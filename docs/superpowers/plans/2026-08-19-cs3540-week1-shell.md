# CS 3540 Week 1 Course Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CS 3540 Canvas cartridge that imports and contains the syllabus plus the five Week 1
onboarding assignments — enough to run the first class on Thu Aug 20, 2026.

**Architecture:** Content authoring against the `content/cs3540/2026/` skeleton created in Plan 1.
No Dart changes. Verification is the existing `dart test` suite (including
`canvas_import_invariants_test.dart`) plus a successful `.imscc` build with the expected object
counts.

**Tech Stack:** YAML + Markdown, `dart run bin/build_canvas_zip.dart`, `dart test`.

**Spec:** `docs/superpowers/specs/2026-08-19-cs3540-2026-fall-design.md` (§7 Grading, §9 Onboarding)

## Deviation from writing-plans, recorded deliberately

This is content authoring, not code. There is no red-green cycle in a syllabus. So: **structural
YAML is pinned verbatim in this plan** (it is error-prone and Canvas fails silently on it), while
**prose bodies are specified by required sections and acceptance criteria** and written during
execution. Verification is build-gated rather than assertion-gated. Plans 5 and 6 (engine spec
core, generator + cron) revert to full TDD treatment.

## Global Constraints

- **Rubric slugs are globally unique.** All CS 3540 slugs are prefixed `cs3540-`. Only
  `cs3540-pass-fail` exists so far; every Week 1 assignment uses it.
- **Grade weights are fixed and approved** — games 42, spec 17, forge 13, attendance 10,
  divergence 10, codex 8. They sum to 100. Onboarding lives inside `codex`; it gates by
  prerequisite, not by points.
- **Timezone:** due dates are 23:59 MT, which is MDT (UTC−6) in Aug–Oct 2026. Express as UTC:
  `23:59 MT` → next day `T05:59:59`.
- **`front_page: syllabus`** requires a page whose slug is exactly `syllabus`. The loader accepts
  a dangling front_page silently — Plan 1 verified this — so nothing will warn if it is wrong.
- **GitHub org is `uvucs3540`.** Repos: `portfolio_<username>_fall_2026`, `engine-spec`,
  `game_<username-or-team>_fall_2026`.
- Never `git push`. Never run `./deploy.sh`.
