# CS 3540 Rubrics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The 18 remaining CS 3540 rubrics, authored, validated, and bundled into the 2h2.us grader.

**Architecture:** Content authoring gated by a validation test that globs every CS 3540 rubric —
so adding a malformed rubric fails the suite rather than failing silently at grading time.

**Tech Stack:** YAML, `dart test`, `mod_node/scripts/refresh-rubrics.mjs`.

**Spec:** `docs/superpowers/specs/2026-08-19-cs3540-2026-fall-design.md` (§7.1)

## Global Constraints

- **Every filename is `cs3540-<slug>.yaml` and the `slug:` field matches the stem exactly.**
  `RubricService.load()` throws otherwise, and the bundle destination is flat and shared with
  CS 3660.
- **Every substantive rubric totals 100 points**; `cs3540-pass-fail` totals 1. The grade weights in
  `course.yaml` do the scaling, so rubric totals stay uniform and comparable.
- **Every criterion has at least two ratings**, highest first, ending at 0 — `RubricService.validate`
  requires non-empty ratings, and a criterion with no zero has no failing case.
- **Criteria describe observable evidence**, not effort. "Fallback renders when the provider is
  unreachable" is gradable; "good error handling" is not.
- Never `git push`. Never run `./deploy.sh`.

**Files:**
- Modify: `test/cc_rubrics_validation_test.dart`

**Interfaces:**
- Produces: a glob-driven test over `content/cs3540/2026/rubrics/*.yaml` asserting slug/filename
  agreement and point totals. Task 2's rubrics are checked by it as they land.

- [x] **Step 1: Replace the hand-listed `cs3540 rubrics` group with a glob**

The test must, for every `*.yaml` in the directory: load it, assert `slug` equals the filename
stem, assert the filename starts with `cs3540-`, assert at least one criterion, assert every
criterion has ≥2 ratings with a 0-point floor, and assert `totalPoints` is 1 for `pass-fail` and
100 otherwise.

- [x] **Step 2: Run — it passes with one rubric, and will catch every later one**

```bash

```
