# Onboarding 1/5 — Submit Your GitHub Username

**Due:** Fri Aug 21, 2026 23:59 MT
**Points:** 1 (pass/fail)
**This is assignment one because everything else waits on it.**

## What to do

If you don't already have a GitHub account, create one at <https://github.com/signup>. **Enable
two-factor authentication** — the course org requires it.

Submit your GitHub username here as a single text entry. Examples: `octocat`, `alex-the-coder`,
`j.smith.dev`.

## Why this is first

Nothing in this course is submitted as a file upload. Every deliverable is a commit, and the
grader reads your repository directly. Until your username exists in the roster, the toolchain
cannot create anything for you.

Once it's submitted, you are provisioned:

1. **Your portfolio repo** — `https://github.com/uvucs3540/portfolio_<your-username>_fall_2026`.
   Devlog, Forge artifacts, and your scope contract live here.
2. **Write access to the class engine spec** — `https://github.com/uvucs3540/engine-spec`. One
   repository, the whole class, sections owned individually.
3. **A grading webhook**, so pushes to your repos are picked up automatically.

You will receive a `maintain` collaborator invite by email. **Accept it within 24 hours** — the
invite expires, and re-issuing it is a manual step that delays you.

## How this is graded

**This is the one assignment submitted in Canvas** — as a text entry, right here.

It has to be, because it is the bootstrap: you have no repository to push to
until this is done. Every other assignment in the course is graded from a git
push, with feedback posted as a GitHub issue on your own repo.

## Acceptance criteria

- Username is a real, valid GitHub username (no spaces, fewer than 40 characters).
- Two-factor authentication is enabled on the account.
- The collaborator invite is accepted within 24 hours of provisioning.
