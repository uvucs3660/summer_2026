# Setting Up Your Claude Pro Subscription

Claude Pro is your textbook for this course. It's required.

## What is Claude Pro?

Anthropic's paid Claude subscription. It includes access to the full Claude family of models (currently Opus 4.7 / Sonnet 4.6 / Haiku 4.5), priority during peak load, and access to Claude Code.

## How to subscribe

1. Visit https://claude.ai/upgrade.
2. Choose Claude Pro ($20/month at the time of writing — verify current pricing).
3. Complete checkout.

## Installing Claude Code

Claude Code is the CLI / desktop / IDE-extension version of Claude that you'll use as your primary dev tool. Once you have Claude Pro, install Claude Code from https://claude.com/claude-code.

Verify installation:

```bash
claude --version
```

## Why this is required

Older versions of this course relied on a textbook. The textbook is replaced by Claude Pro because:

- Claude Pro is *current* in a way no textbook can be — it reflects 2026 industry practice.
- Using it daily teaches AI-mediated workflow, which is the workplace skill of this decade.
- The 5 individual Claude Code artifacts you'll build over the term require Claude Pro to develop.
