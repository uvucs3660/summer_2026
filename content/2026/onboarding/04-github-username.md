# Onboarding 4/5 — Submit Your GitHub Username (Bootstrap)

**Due:** Sun May 10, 2026 23:59 MT
**Points:** 1 (pass/fail)
**Hard prerequisite for Sprint 1 team assignment.**

## What to do

If you don't already have a GitHub account, create one at <https://github.com/signup>. Enable two-factor authentication.

Submit your GitHub username here as a single text-entry. Examples: `octocat`, `alex-the-coder`, `j.smith.dev`.

## What happens next

Once your username is submitted, the course toolchain provisions:

1. **Your personal portfolio repo** at `https://github.com/uvucs3660/portfolio_<your-username>_summer_2026`. You'll receive a `maintain` collaborator invite. Accept it.
2. **Your personal LLM API key** for the class LLM service. The key is delivered via Canvas direct message. **Do not commit the key to any repo, ever.**

You cannot complete onboarding assignments 1, 2, 3, or 5 until you've submitted this one and received your portfolio repo invite.

## Acceptance criteria

- Submitted username is a real, valid GitHub username (no spaces, fewer than 40 chars).
- You accept the collaborator invite within 24h of provisioning.
